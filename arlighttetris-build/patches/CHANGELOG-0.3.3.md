# ArlightTetris 0.3.3

- Corrige los keybinds: ahora solo están activos durante una partida.
- Captura los controles antes de que Minecraft mueva al jugador.
- Bloquea caminar, saltar, agacharse, correr, atacar, usar objetos, soltar objetos e inventario durante la partida.
- A/D/S/W (o las teclas de movimiento configuradas) funcionan como controles alternativos.
- Mantiene flechas, Espacio, Z y C como controles dedicados reconfigurables.
- El jugador conserva la cámara y la tecla Esc.
