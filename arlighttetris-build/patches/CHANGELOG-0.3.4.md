# ArlightTetris 0.3.4

- Caída automática de piezas según nivel.
- Puntaje clásico por líneas, soft drop y hard drop.
- Un nivel cada 10 líneas y aumento progresivo de velocidad.
- Lock delay reducido a 0.4 segundos.
- Captura directa de Espacio, C y Z para evitar que otros mods consuman las teclas.
- HUD con puntos, líneas y nivel.
